# 移动端与 Web 端机器人自动化 UIUX 设计

## 设计原则

- **聊天优先**：机器人是会话能力，不另造割裂的 AI 工作台。
- **自动化透明**：每次动作都显示触发来源、影响范围、执行状态和发起人。
- **先确认再写入**：敏感读取与写操作都以“提议卡片”呈现，用户明确批准后才执行。
- **一套语义、两种布局**：机器人、提议、执行、失败四种状态与文案跨端一致；导航与密度按设备调整。

## 信息架构

| 区域 | 移动端 | Web 端 |
| --- | --- | --- |
| 机器人入口 | 消息页置顶的“AI 助手”会话；搜索可发现 | 会话列表固定入口，带“机器人”标签 |
| 群内触发 | 输入 `@` 后显示机器人建议行 | 输入 `@` 菜单支持键盘上下选择与 Enter 确认 |
| 自动化中心 | 工作台中的“自动化”入口；列表→详情→编辑全屏 | 工作台左侧规则列表，中间编辑器，右侧执行/审计检查器 |
| 待审批任务 | 聊天中的提议卡片；也可在工作台“待我确认”查看 | 顶栏待办计数 + 工作台审批队列 |

## 核心流程

```mermaid
flowchart LR
  A[进入聊天] --> B{独立 AI 会话?}
  B -- 是 --> C[直接提问]
  B -- 否 --> D[@机器人 建议]
  C --> E[机器人回复 / 工具卡片]
  D --> E
  E --> F{是否敏感或写操作?}
  F -- 否 --> G[展示结果]
  F -- 是 --> H[提议卡片]
  H --> I[批准 / 拒绝]
  I --> J[执行状态与审计链接]
```

## 1. 机器人聊天

### 独立 AI 助手会话

- 会话列表置顶，头像使用 `AI`、名称“AI 助手”、辅助标签“机器人”。
- 首次进入显示三个快捷提问：`查询成员`、`总结当前群聊`、`查看机器人能力`；不是空白对话页。
- 输入框占位文案为“直接向 AI 助手提问”；发送中使用消息内骨架，不阻塞继续阅读历史消息。
- 回复类型：普通文本、结构化卡片、工具结果、需要确认的提议、失败提示；所有类型保留时间与发送者标识。

### 群聊 @ 机器人

- 输入 `@` 后，第一项固定为“机器人 · AI 助手”；显示一句能力说明，不显示内部工具名。
- 选中后输入区变为 `@机器人 `；用户仍可编辑、删除或改为普通消息。
- 未启用时不显示可触发建议，管理员在群资料或 Web 端配置中开启；不要让成员发送后才知道不可用。
- 机器人回复引用触发问题，并标记“由群机器人回复”，避免与人工消息混淆。

## 2. 卡片与状态

| 卡片 | 必备内容 | 主操作 |
| --- | --- | --- |
| 工具结果 | 标题、摘要、数据来源、更新时间 | 查看详情 / 复制 |
| 自动化提议 | 将执行的动作、影响对象、风险标签、有效期 | 批准、拒绝 |
| 执行中 | 阶段、开始时间、可取消性 | 查看执行详情 |
| 执行结果 | 成功/失败图标与文字、执行人、审计 ID | 查看审计 |
| 失败 | 不泄露内部异常的说明、可重试条件 | 重试 / 查看详情 |

提议卡片必须在批准前使用中性底色和“需确认”文字；批准按钮为主色，拒绝为次级按钮。任何不可逆动作都额外显示“将影响 N 个对象”。

## 3. 自动化中心

### 移动端

- 工作台显示两个分段：`我的自动化`、`待我确认`。
- 规则列表卡展示：启停开关、触发条件、最近一次结果、失败提示与更多菜单；开关立即更新但失败时回滚并显示 Snackbar。
- 新建规则采用三步全屏流程：**触发条件 → 要执行的动作 → 复核并启用**。每步顶部显示进度，返回不丢草稿。
- 执行详情采用时间线，默认仅展示安全摘要；“查看完整审计”需二次进入。

### Web 端

- ≥1280px 使用三栏：规则列表（280px）、编辑/详情主区、执行与审计检查器（320px）。
- 768–1279px 收起右侧检查器为抽屉；<768px 使用移动端单栏导航。
- 规则编辑器先提供自然语言模板，再显示结构化表单；禁止直接让用户编辑任意脚本。
- 保存草稿、启用、停用、删除位置固定在页头；删除使用确认对话框，启用前显示权限/风险校验结果。

## 4. 可访问性与反馈

- 所有图标按钮提供可读标签；移动端点击目标 ≥44dp，Web 端支持 Tab、Enter、Esc 与可见焦点环。
- 状态不能只靠颜色：成功、告警、失败均有图标和文字。
- 加载使用骨架；空状态提供下一步操作；网络失败保留编辑草稿并提供重试。
- 机器人生成中的动画应短且尊重“减少动态效果”系统设置。

## 页面与组件落点

| 平台 | 页面/组件 | 计划新增能力 |
| --- | --- | --- |
| 移动 Compose | `ChatUI`、`ChatInputArea`、`BotCardMessage` | @ 建议行、提议/执行卡片、AI 首次引导 |
| 移动 Compose | `WorkbenchUI` | 自动化列表、待确认队列、三步规则创建与执行时间线 |
| Web/Electron | `ChatList`、`ChatRoom` | 机器人发现、@ 菜单、统一审批卡片 |
| Web/Electron | 新建 `features/automation` | 三栏规则中心、编辑器、执行检查器 |
