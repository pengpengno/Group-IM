# 工作台功能模块设计

## 1. 目标与范围

工作台是 Group IM 的统一业务入口，帮助用户从消息主界面快速进入高频协作能力。本期只聚合已有能力，不新增独立后端服务或重复维护业务数据。

覆盖端：Web/Electron React 客户端与移动端 Compose 客户端。

## 2. 信息架构

| 模块 | 用户价值 | 首期行为 | 所属既有模块 |
| --- | --- | --- | --- |
| 会话协作 | 进入私聊、群聊与消息处理 | 跳转会话页 | chat |
| 在线会议 | 发起或加入音视频会议 | 跳转会议列表 | meetings / WebRTC |
| 组织通讯录 | 查找组织成员并开始沟通 | 跳转联系人页 | contacts |
| 个人设置 | 配置通知与账号偏好 | 跳转设置页 | settings |

## 3. 交互与验收

1. Web 侧边栏提供“工作台”入口；移动端底部导航提供“工作台”入口。
2. 入口可通过键盘或触摸操作，卡片提供清晰标题和用途说明。
3. 点击任一卡片后进入对应的既有页面，页面数据和状态继续由原模块负责。
4. 在窄屏移动设备上卡片纵向排列，不产生水平滚动。

## 4. 后续迭代

二期可在服务端新增基于角色的应用目录、待办聚合和可配置快捷入口。新增远程配置前，应保留本期本地静态入口作为降级策略。
